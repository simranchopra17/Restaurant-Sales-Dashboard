# 📊 Restaurant Sales Analytics & Performance Dashboard

An interactive Microsoft Excel sales analytics dashboard designed to monitor core restaurant KPIs, customer dining preferences, and transaction trends.

## 📌 Key Metrics & Features
- **Core KPIs:** Total Sales, Sales Quantity, Total Orders, and Average Order Value (AOV).
- **Product Performance:** Identifies top-performing and high-margin food items.
- **Time Analysis:** Peak order hours, day-wise distribution, and meal-time trends.
- **Customer Segmentation:** Breakdown by transaction mode (Cash, Card, Online) and Gender.
- **Interactive Slicers:** Dynamic cross-filtering by Day, Time of Sale, and Transaction Type.

## 📂 Project Files
- `Restaurant_Sales_Dashboard.xlsx` — Excel data model with Pivot Tables, Charts, and Dynamic Slicers.

## 🛠️ Tools Used
- Microsoft Excel (Pivot Tables, Dynamic Charts, Slicers, Data Modeling)
